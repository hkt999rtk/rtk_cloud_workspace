RTK Cloud · deployment design

First trust is a deployment gate, not a runtime fallback.

A new environment creates one short-lived bootstrap leaf, installs the initial internal identities, proves each workload can use its own mTLS certificate, and only then enables MQTT and optional services. The bootstrap leaf is revoked, its CRL is acknowledged, and the session is sealed before normal operation.

The separate public factory hostname, client mTLS boundary and Product signing sequence are documented in the factory enrollment design. Cloud Test Lab is a development test flow and is not for mass production.
